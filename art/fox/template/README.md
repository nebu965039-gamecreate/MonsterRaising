# パーツ制作用の雛型(輪郭のみ)

仮絵(`app/src/main/assets/characters/fox/frames/`)の 48×48 フレームから輪郭だけを抜き出した下絵です。
`tools/make_template.py` で再生成できます(元フレームを差し替えたら再実行)。

| ファイル | 用途 |
|---|---|
| `outline_<pose>_48.png` | 輪郭のみ・48×48・透明背景。**レイヤーの下敷きにする本体** |
| `outline_<pose>_x10.png` | 上の 10 倍拡大(透明背景)。ドット単位で描き込むとき用 |
| `outline_<pose>_x10_grid.png` | 拡大+1px グリッド(8px ごとに太線)・中心線(x=24)・接地線つき。位置確認用 |
| `guide_<pose>_x10.png` | パーツ区分の**目安**(色分け+名称)。厳密な境界ではない |

`<pose>` は `normal`(通常・2 本足視点)と `walk_mid`(歩行の基本ポーズ・脚 4 本)。

## 制作のルール(設計書 3.2・3.3 に準拠)
- **キャンバスは全レイヤー共通の 48×48**。パーツごとに切り出さず、位置は雛型に合わせたまま描く(位置合わせ不要で重ねられる)。
- **接地線は 45 行目の上端**(下から 4 行目まで=行 44 が足先)。全脚とも足先をこの線にそろえる。
- **中心線は x=24**。
- 補間・アンチエイリアスなし。色数は仮絵と同程度(共通 20 色前後)に抑える。
- パーツは設計書の 8 種:頭(目・口を含む)/胴体/右腕/左腕/右足/左足/尻尾/背中。

## 重ね順(奥 → 手前)の目安
背中 → 尻尾 → 奥の腕・足 → 胴体 → 手前の腕・足 → **頭(最前面)**

## 付け根は「隠れる分まで」描く
ズレて見えないよう、体や頭の下に隠れる部分も描いておいてください。
- 首の後ろ(頭の下に隠れる胴体の上端)
- 腕・足の付け根(胴体の下に隠れる、体の内側へ数ピクセル)

これがあれば、頭や脚を 1〜2px 動かしても継ぎ目が出ません(現在の仮絵は、この情報がないため
`tools/make_prototype_frames.py` で付け根を延長して隠しています)。

## 提案するファイル配置
`art/fox/layers/<pose>/<part>.png`(例:`art/fox/layers/normal/head.png`)
レイヤー素材を置いてもらえれば、重ね順とオフセットを指定して各フレームを組み上げるツールを用意します。
